# Troubleshoot the native SATN workflow

Start with the first failed stage and its exact command. Current local maps are
generated by the Rust compiler; the Python `satn` commands below the retained
reference material belong to an older implementation.

## Build

**Symptom:** Cargo fails while building bundled GEOS.

Install Rust/Cargo, CMake, and a C++ compiler, then retry the locked build:

```shell
cargo build --release --manifest-path rust/Cargo.toml --locked
```

The build links GEOS statically, so the compiled executable does not need a
separate GEOS installation.

## Input snapshot

**Symptom:** `satn-rs` reports that a snapshot file is missing or invalid.

Check the resolved `source.snapshot_dir/source.snapshot_id` path in the Area
Definition and confirm the snapshot contains the expected GeoJSON files. The
native compiler consumes pinned files; it does not repair or reacquire them.
Keep the original evidence immutable and use a new snapshot identity when
replacing inputs.

## Mechanical preparation

**Symptom:** roads appear as source corridors but not as routable candidates.

Source accounting and graph topology are separate. A source road can remain
visible when its geometry does not match routable graph edges. Check source
identity, coordinate reference, geometry, and the reported topology status;
do not read classification as proof of provision or connectivity.

**Symptom:** no candidate neighbourhood is emitted.

The optional built-up-area input must contain polygon or multipolygon features
with ONS `BUA22CD` and `BUA22NM` properties. A candidate face must lie fully
inside a sourced built-up area and have positive-length frontages on at least
two distinct official classified roads. Point contacts, unnamed roads, and
feature segment IDs do not establish a separate frontage. See the
[candidate-neighbourhood guide](guides/candidate-neighbourhoods.md).

## Classifier and replay

**Symptom:** a live decision remains unresolved.

Inspect the retained task, attempt status, evidence packet, offered choices, and
validation result in the history. An unresolved outcome is expected when the
classifier cannot support an offered choice or validation rejects the response.
An optional specialist is called only on the configured escalation path. Do
not turn an unresolved result into a free-text choice or add unoffered geometry.
See the [decision-process guide](concepts/decision-process.md).

**Symptom:** replay rejects a retained operation.

Replay requires the same bound task and offered choice. Check the branch head,
recorded operation, and configuration/snapshot inputs. Replay does not call a
provider to repair stale or mismatched decisions.

## Map and publication

**Symptom:** the native map is blank when opened as a local file.

Serve the output directory over HTTP:

```shell
python3 -m http.server 8000 --directory build/rust-banes
```

**Symptom:** the Pages release does not deploy.

The release workflow checks the `satn-pages.zip` artifact and renders every map
with Chromium before deployment. Inspect the first failing map and rendering
diagnostic; the workflow does not compile the network or regenerate the bundle.

## Report a defect

Include the Area Definition path, snapshot ID, exact native command, first
failing stage, relevant task or candidate ID, and the smallest source/artifact
fingerprint needed to reproduce the problem. Do not attach controlled or
personal evidence to a public issue.
